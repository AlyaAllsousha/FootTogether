**FoodTogether**

*Приложение для совместного заказа продуктов из сервисов доставки*

**Идея**
Люди смогут объединятся по месту жительства и заказывать продукты от имени 1 пользователя. Благодаря этому доставка становится дешевле (при определенной сумме в некоторых сервисах даже бесплатной).

**Фукнционал**
1) Уведомления. При желании пользователя поесть, он включает функцию "уведомить голодных". У других пользователей, у которых статус "голодный" на экране возникает уведомление, что кто то рядом хочет заказать еду. Есть варианты подписки на определённый тип еды или магазин, чтобы фильтровать уведомления.
2) На карте отображены ближайшие пользователи, готовые к совместным закупкам
3)  Есть возможность выбирать, из какого сервиса пользователи будут заказывать еду
4)  При платной доставке счет делится поровну между пользователями
5)  Каждый пользователь прикреплен к определенному аккаунту, в зависимости от своего местоположения или личных предпочтений.
6)  При выборе сервиса, пользователь переходит на его сайт и добавляет необходимые продукты в общую корзину. После этого индивидуально расчитывается стоимость доставки и выбранных товаров
